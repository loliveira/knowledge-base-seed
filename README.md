# Knowledge Base Seed

Template privado para iniciar uma Knowledge Base versionada em Markdown.

Este repositório serve como base para times que precisam organizar conhecimento estratégico, técnico, editorial e operacional sem depender de CMS.

## Estrutura

```text
/docs
  /00-base
  /01-produtos
  /02-tecnologia
  /03-mensagens
  /04-operacao
  /05-casos
  /06-sinteses
  /07-open-source
```

## Por onde começar

1. ajuste [docs/00-base/00_mapa.md](./docs/00-base/00_mapa.md)
2. revise [docs/04-operacao/01_schema.md](./docs/04-operacao/01_schema.md)
3. personalize [docs/00-base/05_lexico.md](./docs/00-base/05_lexico.md)
4. siga [docs/04-operacao/06_manual-6-comandos.md](./docs/04-operacao/06_manual-6-comandos.md)

## Uso esperado

- documentação institucional
- base pública ou semi-pública
- fonte para agentes e MCP
- memória operacional versionada
