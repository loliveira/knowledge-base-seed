# Transcrições

Para cada call, um par de arquivos (crie com `scripts/nova-ingestao.sh`):

- `AAAA-MM-DD_call-participantes_assunto_transcricao-bruta.md` — fala bruta (fonte, não fato)
- `AAAA-MM-DD_call-participantes_assunto_notas-e-decisoes.md` — nota derivada com proveniência

Veja [ingestão de calls](../../docs/09-operacao/05_ingestao-de-calls.md). Transcrições longas
ou sensíveis ficam fora do Git e são referenciadas por link. **Transcrição com dado de
paciente é sempre sensível**: só a nota derivada anonimizada é versionada.
